Local store metadata coverage

metadata/completeness · all · default severity: warning

Why this matters and what is checked

Absent local fields and screenshots do not prove a submission failure: existing store listings or deliberate localization fallback may supply them. Summarized coverage warnings are separate from invalid present values.

How to fix it

Review remote listing values and localization fallback, or add the missing local assets. Promote metadata/completeness to error for a fully self-contained listing; --strict also fails on warnings.

Policy and reference

https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information

Configuration

Set a severity of error, warning or note, or disable the check in shipcheck.config.json when it is intentionally inapplicable:

{
  "rules": {
    "metadata/completeness": "off"
  }
}
