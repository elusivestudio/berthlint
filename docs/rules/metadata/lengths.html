Store metadata lengths

metadata/lengths · all · default severity: error

Why this matters and what is checked

Listings exceeding store field limits cannot be submitted unchanged. Apple keywords use UTF-8 bytes; other fields are counted as Unicode code points.

How to fix it

Shorten the field to its store limit. Apple keywords use UTF-8 bytes; other fields use Unicode code points.

Policy and reference

https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information

Configuration

Set a severity of error, warning or note, or disable the check in berthlint.config.json when it is intentionally inapplicable:

{
  "rules": {
    "metadata/lengths": "off"
  }
}
