Localization field parity

metadata/localizations · all · default severity: warning

Why this matters and what is checked

Missing default-locale translations can create incomplete listings. Required-field absence is reported by metadata/completeness and blank required values by metadata/required-fields, not repeated here. Optional-field parity is advisory; remote fallback is not inspected.

How to fix it

Provide the default locale and translate fields present in it; review intended store fallback behavior.

Policy and reference

https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information

Configuration

Set a severity of error, warning or note, or disable the check in shipcheck.config.json when it is intentionally inapplicable:

{
  "rules": {
    "metadata/localizations": "off"
  }
}
