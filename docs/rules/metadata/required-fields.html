Required store metadata fields

metadata/required-fields · all · default severity: error

Why this matters and what is checked

Present mandatory listing fields must contain a meaningful value of the minimum length. Absent files are reported separately as metadata/completeness coverage, not definite store rejection.

How to fix it

Add the missing localized fastlane text field, or supply a meaningful value of the minimum length.

Policy and reference

https://support.google.com/googleplay/android-developer/answer/9859152

Configuration

Set a severity of error, warning or note, or disable the check in berthlint.config.json when it is intentionally inapplicable:

{
  "rules": {
    "metadata/required-fields": "off"
  }
}
