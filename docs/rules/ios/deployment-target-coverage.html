iOS deployment target coverage

ios/deployment-target-coverage · ios · default severity: note

Why this matters and what is checked

Missing or unresolved deployment settings cannot be certified from project text. External xcconfig files, generated settings and build overrides need independent verification.

How to fix it

Resolve IPHONEOS_DEPLOYMENT_TARGET using Xcode build settings; standalone plists may supply MinimumOSVersion. Only verified Xcode deployment ranges are checked.

Policy and reference

https://developer.apple.com/support/xcode/

Configuration

Set a severity of error, warning or note, or disable the check in berthlint.config.json when it is intentionally inapplicable:

{
  "rules": {
    "ios/deployment-target-coverage": "off"
  }
}
