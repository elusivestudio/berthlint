iOS SDK declaration coverage

ios/sdk-coverage · ios · default severity: note

Why this matters and what is checked

A project normally selects iphoneos, not a concrete SDK version. Missing user-declared SDK information must be reported instead of implying toolchain compliance.

How to fix it

Supply iosSdkVersion (or --ios-sdk-version) and optionally xcodeVersion. Use the build SDK, not the minimum deployment target. Verify the archive's actual toolchain separately.

Policy and reference

https://developer.apple.com/news/upcoming-requirements/?id=04282026a

Configuration

Set a severity of error, warning or note, or disable the check in shipcheck.config.json when it is intentionally inapplicable:

{
  "rules": {
    "ios/sdk-coverage": "off"
  }
}
