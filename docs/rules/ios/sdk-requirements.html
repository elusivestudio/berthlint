Declared iOS SDK and Xcode requirements

ios/sdk-requirements · ios · default severity: error

Why this matters and what is checked

App Store uploads must use the required SDK and Xcode releases. Versions are user declarations, not detected toolchains; SDKROOT=iphoneos and deployment targets do not establish an SDK version.

How to fix it

Build with the required release SDK and Xcode. Set iosSdkVersion/xcodeVersion in config or pass --ios-sdk-version/--xcode-version; verify the actual archive separately.

Policy and reference

https://developer.apple.com/news/upcoming-requirements/?id=04282026a

Configuration

Set a severity of error, warning or note, or disable the check in berthlint.config.json when it is intentionally inapplicable:

{
  "rules": {
    "ios/sdk-requirements": "off"
  }
}
