iOS deployment target compatibility

ios/deployment-target · ios · default severity: error

Why this matters and what is checked

The minimum supported OS is distinct from the build SDK. Targets must be numeric, meet the dated App Store OS minimum, not exceed the declared SDK, and meet the documented deployment floor for a known declared Xcode family.

How to fix it

Set IPHONEOS_DEPLOYMENT_TARGET to a supported OS version in the selected build configuration. Do not raise it to the SDK version unnecessarily; confirm xcconfig and CI overrides.

Policy and reference

https://developer.apple.com/support/xcode/

Configuration

Set a severity of error, warning or note, or disable the check in berthlint.config.json when it is intentionally inapplicable:

{
  "rules": {
    "ios/deployment-target": "off"
  }
}
