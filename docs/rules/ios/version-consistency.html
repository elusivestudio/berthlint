App and extension version consistency

ios/version-consistency · ios · default severity: warning

Why this matters and what is checked

App and embedded extension versions should agree. Only fully resolved version/build pairs in one project are compared; missing or unresolved targets are excluded. Independently versioned apps may need an override.

How to fix it

Align app and embedded extension versions and builds. Independently versioned apps may disable this rule.

Policy and reference

https://developer.apple.com/documentation/bundleresources/information-property-list

Configuration

Set a severity of error, warning or note, or disable the check in berthlint.config.json when it is intentionally inapplicable:

{
  "rules": {
    "ios/version-consistency": "off"
  }
}
