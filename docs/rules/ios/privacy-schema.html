Privacy manifest structure

ios/privacy-schema · ios · default severity: error

Why this matters and what is checked

Malformed privacy fields can prevent correct submission. This validates structure and reason-code syntax, not Apple's approval of a reason for a category.

How to fix it

Correct manifest field types and supply nonempty reason codes and complete collected-data declarations.

Policy and reference

https://developer.apple.com/documentation/bundleresources/describing-use-of-required-reason-api

Configuration

Set a severity of error, warning or note, or disable the check in berthlint.config.json when it is intentionally inapplicable:

{
  "rules": {
    "ios/privacy-schema": "off"
  }
}
