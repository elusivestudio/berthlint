Google Play target API level

android/target-sdk · android · default severity: error

Why this matters and what is checked

New apps and updates must meet the published target API threshold for their device category. This is not the existing-app availability threshold.

How to fix it

Set a literal targetSdk in the app module, or verify dynamic Gradle values manually. Select the correct androidDevice in config.

Policy and reference

https://support.google.com/googleplay/android-developer/answer/11926878

Configuration

Set a severity of error, warning or note, or disable the check in shipcheck.config.json when it is intentionally inapplicable:

{
  "rules": {
    "android/target-sdk": "off"
  }
}
