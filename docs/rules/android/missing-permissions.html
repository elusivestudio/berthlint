Potential missing Android permissions

android/missing-permissions · android · default severity: warning

Why this matters and what is checked

Camera, recording and location API tokens are compared to declared permissions. Libraries, module ownership and merged manifests need manual review.

How to fix it

Review source/module ownership and add the needed uses-permission declaration. Library manifests may supply it at merge time.

Policy and reference

https://developer.android.com/guide/topics/manifest/manifest-intro

Configuration

Set a severity of error, warning or note, or disable the check in berthlint.config.json when it is intentionally inapplicable:

{
  "rules": {
    "android/missing-permissions": "off"
  }
}
