Increasing Android version code

android/version-increment · android · default severity: error

Why this matters and what is checked

An update must use a versionCode higher than the previous release. Comparison requires an explicit git tag or configured previous code.

How to fix it

Increase versionCode above the previous release. Set baselineTag or previousAndroidVersionCode to enable comparison.

Policy and reference

https://developer.android.com/studio/publish/versioning

Configuration

Set a severity of error, warning or note, or disable the check in shipcheck.config.json when it is intentionally inapplicable:

{
  "rules": {
    "android/version-increment": "off"
  }
}
