Requirements freshness

system/requirements-stale · all · default severity: warning

Why this matters and what is checked

Store policies change independently of the tool. A dated local policy snapshot needs periodic verification against official sources.

How to fix it

Re-verify store policies against the linked official documentation and update the versioned requirements data.

Policy and reference

https://support.google.com/googleplay/android-developer/answer/11926878

Configuration

Set a severity of error, warning or note, or disable the check in shipcheck.config.json when it is intentionally inapplicable:

{
  "rules": {
    "system/requirements-stale": "off"
  }
}
