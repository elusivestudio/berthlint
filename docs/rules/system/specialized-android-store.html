Specialized Android screenshot coverage

system/specialized-android-store · android · default severity: warning

Why this matters and what is checked

Phone/tablet asset checks do not prove compliance for Wear, Automotive, TV or XR. Unsupported groups must be reviewed manually rather than silently passing.

How to fix it

Review Wear, Automotive, TV or XR screenshot and listing policies manually; only phone/tablet assets are validated.

Policy and reference

https://support.google.com/googleplay/android-developer/answer/9866151

Configuration

Set a severity of error, warning or note, or disable the check in berthlint.config.json when it is intentionally inapplicable:

{
  "rules": {
    "system/specialized-android-store": "off"
  }
}
