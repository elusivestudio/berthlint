shipcheck — static native mobile release checks

Release checks, explained

Run shipcheck in a native iOS or Android repository to check release settings and fastlane store metadata without building or uploading.

Each finding includes a fix suggestion and a policy link. SDK and Xcode versions are user declarations, not proof of the toolchain actually used to build.
